# CAT Trucks Editorial Website

A responsive single-page Next.js App Router website focused on Caterpillar haul trucks.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Deploy to Vercel

1. Push this folder to a GitHub repository.
2. In Vercel, choose **Add New → Project** and import the repository.
3. Keep the framework preset as **Next.js** and the build command as `next build`.
4. Click **Deploy**.

No environment variables are required. Product photography is loaded from externally hosted image sources, so an internet connection is required. Replace these with licensed local assets before commercial use. This is an independent concept page and is not an official Caterpillar website.
